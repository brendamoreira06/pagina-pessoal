# Página Pessoal — Brenda Moreira da Silva

Atividade Prática 2 da disciplina **GAC116 - Programação Web**, que consiste no desenvolvimento de uma página pessoal (portfólio web) em duas versões distintas, utilizando frameworks CSS diferentes para a interface — mantendo o mesmo conteúdo.

## Acesse online

- **Página inicial (com as duas opções):** https://brendamoreira06.github.io/pagina-pessoal/index.html
- **Versão Bootstrap:** https://brendamoreira06.github.io/pagina-pessoal/bootstrap/index.html
- **Versão Tailwind CSS:** https://brendamoreira06.github.io/pagina-pessoal/outro-framework/index.html


## Frameworks utilizados

| Versão              | Framework CSS  |
| -------------------- | -------------- |
| `bootstrap/`          | Bootstrap 5.3  |
| `outro-framework/`    | Tailwind CSS   |

## Funcionalidades

- Layout responsivo (mobile, tablet e desktop)
- Tema claro e tema escuro, com alternância manual e persistência via `localStorage`
- Seções: Sobre, Habilidades, Trajetória (formação/estágio) e Contato
- Conteúdo equivalente entre as duas versões, variando apenas o framework de interface
